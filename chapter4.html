1. What are HTML Attributes?

HTML attributes provide additional information about HTML elements.

Attributes are written inside the opening tag.

13. Attribute Summary

Attribute Purpose Example
id Gives a unique identity id="header"
class Groups multiple elements class="student"
style Applies inline CSS style="color:red;"
title Shows tooltip title="Information"
lang Specifies language lang="en"
dir Specifies text direction dir="rtl"
