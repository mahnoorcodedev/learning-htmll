14. Common Image Formats

  • JPG/JPEG: Best for photographs.
  • PNG: Useful for transparency.
  • GIF: Supports simple animations.
  • SVG: Good for logos and scalable graphics.
  • WebP: Modern format with good compression.

15. Image Best Practices

  • Always use the alt attribute.
  • Use meaningful image filenames.
  • Resize very large images before uploading.
  • Use the correct image format.
  • Use responsive images when necessary.
  • Use lazy loading for images that are not immediately visible.
